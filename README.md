# YoChef

A mobile cooking application built with React Native and Expo.

## Project Overview

YoChef is a cooking companion app designed to help users discover recipes, plan meals, and organize their cooking activities.

## Tech Stack

- **Framework**: React Native with Expo
- **Language**: TypeScript
- **Backend**: Node.js
- **Database**: PostgreSQL
- **ORM**: Prisma
