# Architecture Decisions

This directory contains Architecture Decision Records (ADRs) for YoChef.

## What is an ADR?

An ADR documents a significant architectural decision, including:

- The context and problem
- The decision made
- The consequences (positive and negative)

## When to Create an ADR

Create an ADR when:

- Making a significant architectural choice
- Selecting between competing options
- Adopting a new technology
- Making a constraint that affects multiple components

## ADR Format

See `ADR-001-example.md` for the template.
