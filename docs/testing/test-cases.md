## Priority Test Cases

### Authentication

1. User can register with valid data
2. User can login with correct credentials
3. Invalid credentials return error
4. Duplicate email registration fails
5. JWT token is valid for protected routes

### Recipe Management

1. User can create a recipe
2. User can view recipe details
3. User can update their own recipe
4. User cannot update others' recipes
5. User can delete their own recipe
6. Recipe search returns relevant results
7. Recipe filtering works correctly

### Community Features

1. User can rate a recipe
2. User can add comment to recipe
3. User can upload cooking photo
4. User can view recipe comments
5. User can delete their own comment

### Shopping List

1. User can create shopping list
2. User can add ingredients from recipe
3. User can check off items
4. User can remove items
5. User can delete shopping list

## Edge Cases

1. Empty search results
2. Invalid recipe ID
3. Missing required fields
4. Expired JWT token
5. Network failure handling
